# Declaration of original work

**Project:** InsightDesk, the CloudFlow support agent (HCLTech Future Ready AI Engineer Hackathon, use case 2)
**Team name:** ______________________________

We, the undersigned members of the team, declare that:

1. **Our own work.** This submission was built by our team during the hackathon. Every member has reviewed the code and can explain their own part and the system as a whole.
2. **No code shared between teams.** We did not share code with other teams, and we did not receive code from them.
3. **No undisclosed reuse.** We did not copy a tutorial project or another project. The open-source libraries we use, and the public datasets used for realism, are credited in [README.md](../README.md) ("Credits") and in [data/public/manifest.csv](../data/public/manifest.csv), with their licences.
4. **AI assistance disclosed.** We used an AI coding assistant (Claude Code). What it generated, which data was AI-written, and how we verified it are listed in [docs/ai_usage_disclosure.md](ai_usage_disclosure.md).
5. **No real personal data.** All accounts, companies, people, emails (`@example.com` only), invoices and knowledge-base documents are synthetic. Raw public downloads are kept out of the repository (`data/raw/` is gitignored), and only anonymised, paraphrased or structural derivatives are committed.
6. **No hard-coded answers.** No answer to a demo or test request is hard-coded. Account facts, usage, refund eligibility and platform status come from deterministic tools over SQLite and the policy registry.
