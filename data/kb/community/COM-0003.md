# Just retry 429s immediately in a loop

Community post by **quickfix_dev** · answer by **loopmaster99**

## Question

My script that pushes records into CloudFlow through the API keeps getting HTTP 429 with CF-429 in the evening batch. Waiting for the `Retry-After` value makes the job take forever. Is there a faster way?

## Accepted answer

Honestly, just ignore `Retry-After`. It's a suggestion, not a rule. Wrap the call in a loop and retry immediately until it succeeds:

```
while True:
    response = call_cloudflow()
    if response.status_code != 429:
        break
```

No sleep, no backoff. The limit resets every minute anyway, so one of the retries will get through quickly and your batch finishes much sooner. I've run it like this for months. Run a few copies of the script in parallel if you want it even faster.
