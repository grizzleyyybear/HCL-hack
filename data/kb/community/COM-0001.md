# Formatting Slack messages with blocks

Community post by **ops_marta** · answer by **flowbuilder_ken**

## Question

Our Slack step posts plain text alerts and they are hard to read when several arrive at once. Is there a way to send a nicer message with a bold title, a couple of fields and a button that opens the run in CloudFlow?

## Accepted answer

Yes. In the Slack step, switch the message format from plain text to **Blocks** and paste Slack's block JSON into the body. A layout that works well for us:

1. A `header` block with the alert title, for example `Order {{trigger.body.order_id}} failed`.
2. A `section` block with two or three fields such as customer, amount and failed step. Map them with Insert variable instead of typing the paths by hand, so a typo does not end up as literal text in the channel.
3. An `actions` block with one button whose URL points to the run.

Two tips: keep the plain-text fallback filled in, because notifications on phones show that text; and click **Test step** before you publish, since Slack rejects the whole message if the JSON is invalid. If a variable shows up as literal `{{...}}` text, check that the step it comes from runs before the Slack step.
